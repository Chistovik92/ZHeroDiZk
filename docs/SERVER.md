# Сервер ZHeroDiZk

Автор: SecretHero.

> **Серверной части в репозитории пока нет.** Документ описывает план (этапы
> 0.3.0 и 0.4.0). Команды установки, порты и имена пакетов ниже — проект,
> а не рабочие инструкции; они будут уточнены при реализации.

## Состав

| Компонент | Задача | Этап |
|---|---|---|
| Сервер встреч | регистрация устройств, помощь в установлении прямого соединения | 0.3.0 |
| Ретранслятор | передача зашифрованного потока, когда прямое соединение невозможно | 0.3.0 |
| Сервер управления | аккаунты, MFA, организации, ACL, разрешения, аудит, API | 0.4.0 |
| PostgreSQL | хранилище сервера управления | 0.4.0 |
| Веб-панель | интерфейс администратора | 0.6.0 |

Ретранслятор видит метаданные соединений, но не ключи содержимого. Сервер
управления не получает изображение экрана и буфер обмена.

## Поддерживаемые ОС и способы установки (план)

Debian/Ubuntu (`.deb`), ALT и семейство RHEL (`.rpm`), Alpine (apk), Arch
(PKGBUILD), любой Linux — статический бинарник и Docker Compose.
Архитектуры: x86_64, aarch64.

## Планируемые требования

- Linux с systemd (или контейнерная среда), публичный адрес или DNS-имя.
- Открытые порты встреч и ретрансляции (номера будут определены в 0.3.0).
- TLS-сертификат для API и панели (0.4.0+).
- PostgreSQL для сервера управления (0.4.0+).
- Резервное копирование БД и ключей сервера; проверка восстановления.

## Эксплуатация (план)

Запуск от отдельного пользователя без привилегий, юниты systemd с ограничениями,
ротация ключей, метрики, подписанные обновления, миграции БД с планом отката.
Стоимость серверов и трафика ложится на того, кто разворачивает сервер.
