# Лицензионная основа

Новые файлы: AGPL-3.0-only. Полный неизменённый текст лицензии — LICENSE.
RustDesk 1.4.8 сохраняет собственную LICENCE и все уведомления. Его зависимости,
подмодули, графика, кодеки, UI и сценарии сборки проверяются пофайлово при импорте.
Наличие AGPL у корня не делает все зависимости автоматически AGPL.

Перед распространением клиента: список компонентов/SBOM, проверка лицензий,
соответствующие исходники и build scripts, уведомление об изменениях,
ссылки на исходники в UI и загрузках, собственные имя и графика.
Не включать RustDesk Pro или иные закрытые компоненты без прав.
В частности, выбирать и проверять Flutter-путь; не включать старую Sciter
библиотеку в полностью открытый дистрибутив по умолчанию.

Раздел 13 AGPL учитывать для изменённого сетевого ПО. Политика проекта:
все официальные функции бесплатно, без проверки активации. AGPL не запрещает
коммерческое использование или продажу чужими распространителями.

## Проверка закреплённого подмодуля

Клиент с SHA `3c574a41821170f89f38141a493e127145dbf82d` закрепляет
`libs/hbb_common` на `387603f47cbb15c0d3dc3d67ae3396d3eb707daf`.
На этой ревизии в корне отдельного репозитория hbb_common нет файла лицензии,
а в Cargo.toml нет поля license/license-file. Это незакрытый пункт проверки:
нельзя автоматически пометить компонент AGPL только из-за лицензии родителя.
Перед распространением требуется установить применимые условия по исходникам
и уведомлениям правообладателя. Полный аудит транзитивных зависимостей ещё впереди.

- Дерево подмодуля: https://github.com/rustdesk/hbb_common/tree/387603f47cbb15c0d3dc3d67ae3396d3eb707daf
