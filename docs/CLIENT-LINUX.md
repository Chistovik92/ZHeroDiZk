# Linux-клиент: первая сборка

Это проверка сборки закреплённого RustDesk 1.4.8 с Flutter, а не готовый
самостоятельный ZHeroDiZk. Интерфейс, идентификаторы, конфигурация и сетевое
поведение пока остаются upstream. Наш crate правил доступа не подключён.
Не запускайте эксперимент рядом с рабочим RustDesk: используется его конфигурация.

## Запуск сборки

После слияния workflow в основную ветку: GitHub → Actions →
Linux client baseline → Run workflow. Полная сборка запускается вручную;
обычные проверки исходников продолжают запускаться на push/PR.
Первый успешный запуск и проверенный коммит записаны в STATUS.md.

## Что собирается

Workflow `Linux client baseline` получает точный SHA из `upstream.lock.json`
и подмодули, проверяет чистоту исходников, создаёт Dart/Rust bridge,
компилирует библиотеку и Flutter-интерфейс на Ubuntu 22.04 x86_64.
Патч Flutter SDK применяется один раз: уже пропатченный кеш принимается,
конфликтующие изменения вызывают ошибку.
Версии Rust 1.75.0, Flutter 3.22.3 для bridge и 3.24.5 для GUI,
vcpkg `120deac3062162151622ca4860575a33844ba10b` взяты из upstream CI.
Используется Flutter, Sciter runtime не добавляется.

Сборка повторяет исходную цепочку, но пока не является побитово воспроизводимой:
Dart-зависимости разрешаются через pub get, системные пакеты приходят из Ubuntu.
Сборка на Ubuntu не подтверждает совместимость с ALT/Simply.

## Проверка и запуск

После локального повторения шагов workflow пакет находится в
`vendor/client/flutter/build/linux/x64/release/bundle/`.
Из терминала обычного пользователя в графическом сеансе:

```bash
python3 zherodizk.py --doctor
python3 zherodizk.py
```

Launcher проверяет среду перед запуском. В X11 отсутствие libxdo или функций
мыши останавливает запуск с объяснением. Проверяются libxdo.so.4, libxdo.so.3,
libxdo.so в порядке upstream; libxdot.so.4 не заменяет эту библиотеку.
Предупреждение Wayland не доказывает работоспособность управления.
Запуск напрямую через `rustdesk` обходит launcher; это пока не проверка внутри GUI.

В Simply/ALT для известного случая отсутствия libxdo установите из root-терминала:

```bash
apt-get install xdotool
```

Затем перезапустите клиент от обычного пользователя. Будущий ALT-пакет должен
объявлять зависимость от поставщика libxdo, а не рассчитывать на ручную установку.

## Что подтверждает CI

Компиляцию, наличие бинарников, разрешение динамических библиотек,
запуск `--version` и диагностического launcher в Xvfb.
CI не проверяет реальные клики, изображение, соединение или работу служб.
Исполняемые файлы пока не публикуются: Actions сохраняет только отчёты.

Следующий стенд: Simply p11/XFCE/X11 как принимающий компьютер, Windows и
Android как управляющие; проверить движение, левую/правую кнопку,
двойной клик, прокрутку, перетаскивание и клавиатуру. До этого,
проверки лицензий/исходников и правил доступа публичного релиза нет.
