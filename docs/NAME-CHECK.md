# Проверка названия — 12 сентября 2026

Результат: **ZeroDisk уже используется программой**.

Первичный источник: https://github.com/cumakurt/ZeroDisk
Описание владельца: Linux-программа очистки дисков на Rust.
GitHub metadata: создан 2026-04-28, основной язык Rust, репозиторий публичный,
не архивирован на дату проверки. Это точное совпадение написания.

Есть также историческое использование ZeroDisk в рекламе ПО Quaid Software:
https://archive.org/stream/PC_Tech_Journal_vol03_n08/PC_Tech_Journal_vol03_n08_djvu.txt
Оно вторично для нашего решения: современного точного совпадения уже достаточно.

Поиск игр: запросы ZeroDisk game, точного имени по Steam и itch.io не дали
подтверждённой карточки игры с этим названием. Это не доказательство отсутствия
всех игр. Поисковая индексация неполна.

Проверка не является поиском товарных знаков и не устанавливает юридическую
доступность названия, доменов или имён пакетов. Перед публичным запуском выбранное
новое имя нужно проверить отдельно по нужным юрисдикциям и каналам распространения.

Первоначальное решение: оставить ZeroDisk временным именем до выбора нового.
Текущее решение приведено ниже: проект называется ZHeroDiZk.

## Дополнительный кандидат: ZHeroDiZk

Пользователь предложил проверить это написание во время работы.
На 2026-09-12:
- GitHub connector search_repositories(query="ZHeroDiZk") → repositories: [].
- Точный веб-поиск "ZHeroDiZk", близкое "ZHeroDisk"/"zherodisk" и запросы
  по github.com, store.steampowered.com, itch.io, play.google.com: подтверждённых
  точных совпадений не обнаружено. Некоторые результаты были нерелевантными
  заменами поисковика; они не считаются совпадениями.
- Прямой поиск внутри каталогов Steam/Google Play/itch.io не проводился:
  проверена только доступная веб-индексация этих сайтов.
- Домены, регистрационные базы товарных знаков и реестры package names
  не проверялись. Свобода названия юридически не установлена.

Вывод: кандидат предпочтительнее ZeroDisk по отсутствию найденных точных
совпадений. Предлагаемое стабильное написание: ZHeroDiZk, техническое: zherodizk.
Восприятие на слух может отличаться: Dizk легко перепутать с Disk.
После проверки пользователь создал и передал репозиторий
https://github.com/Chistovik92/ZHeroDiZk. Название принято для разработки.
Пустой результат поиска выше относится к моменту ДО создания нашего репозитория.
Текущие GitHub-совпадения нужно отличать от собственного проекта.
