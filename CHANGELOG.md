# История изменений

Автор: SecretHero. Формат версий — [docs/VERSIONING.md](docs/VERSIONING.md).
Выпущены пре-релизы v0.1.1–v0.1.5 (только исходный код): https://github.com/Chistovik92/ZHeroDiZk/releases

## 0.3.x — не выпущено (в разработке, проверено в CI)

- 0.3.1–0.3.2: закреплённые серверные исходники, `bootstrap.py --component server`,
  `prepare_server.py`, `server/identity.json`; бинарники `zhd-rendezvous`, `zhd-relay`,
  `zhd-utils`; удалена проверка обновлений на стороннем сервере; статические musl-сборки.
- 0.3.3–0.3.4: пакеты deb/rpm/tarball, юниты systemd (ограничения, UMask 0077), Docker и Compose,
  установочные тесты на 8 дистрибутивах.
- 0.2.2 (часть): профиль Windows-идентичности (`client/windows-identity.json`,
  `tools/check_windows_identity.py`); сборка Windows ещё не подтверждена.

## 0.1.5 — выпущено (v0.1.5)

- `tools/sbom.py`: CycloneDX 1.5 по `cargo metadata` и `pubspec.lock`; лицензии Dart
  не выдумываются, помечаются UNKNOWN. 5 тестов (всего 44). Шаг добавлен в сборку Linux,
  в реальной сборке отработал: 967 компонентов, 223 без определённой лицензии (214 Dart).

## 0.1.4 — выпущено (v0.1.4)

- Аудит лицензии `hbb_common`: docs/LICENSE-AUDIT.md.

## 0.1.3 — выпущено (v0.1.3; полная сборка Linux на `1280341` успешна)

- Исправление: дубль ключа `authors` в манифесте access-policy ломал Rust-тесты в CI (найдено CI, исправлено).

- Влита ветка собственной идентичности Linux-клиента: имя, бинарник, GTK-ID,
  изолированные конфигурация, логи и IPC; проверка идентичности по выводу клиента.
- `prepare_client.py`: чтение и запись в UTF-8, сохранение окончаний строк,
  откат уже изменённых файлов при сбое записи; два новых теста (всего 39).
- `.gitattributes`: LF во всём репозитории.
- Убраны лишние упоминания стороннего проекта из пользовательских сообщений
  и имён файлов отчёта; обязательные уведомления лицензий сохранены.
- Документация: дорожная карта с версиями, структура проекта, платформы, сервер,
  использование, разработка, версии, авторство SecretHero.
- Не проверено: полная сборка Linux-клиента с новой идентичностью, Rust-тесты
  на этой ревизии (запускаются в CI).
